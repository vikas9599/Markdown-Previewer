Markdown Cheat Sheet & Keyboard Shortcuts

Keyboard Shortcuts

  • Ctrl+F - Find
  • Ctrl+H - Find & Replace
  • Ctrl+Z - Undo
  • Ctrl+Y - Redo
  • Ctrl+/ - Show this help
  • Ctrl+B - Bold
  • Ctrl+I - Italic
  • Ctrl+K - Insert link
  • Ctrl+S - Save (auto-saves locally)
  • F11 - Toggle fullscreen

Markdown Syntax

  • Headings: # H1, ## H2, ### H3
  • Bold: **text** or __text__
  • Italic: *text* or _text_
  • Strikethrough: ~~text~~
  • Code: `code` or ```code block```
  • Link: [text](url)
  • Image: ![alt](url)
  • List: - item or 1. item
  • Blockquote: > text
  • Table: Use toolbar button or type manually
  • Horizontal Rule: --- or ***
